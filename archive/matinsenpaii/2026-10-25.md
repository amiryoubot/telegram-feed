۱. اجرای DSH:  
`npx @deepseek-ai/dsh web`

`git clone https://github.com/Ebony-Vinyl/dsh-our-free-model`

`dsh plugin --profile web add /path/to/dsh-our-free-model`  
۴. ری‌استارت DSH؛ مدل‌ها در model picker ظاهر می‌شوند.
