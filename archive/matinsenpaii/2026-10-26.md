**ساخت استارتاپ و 50 میلیون کسب درآمد توی 30 روز با Claude Code | قسمت 1**  

توی این سری ویدئو، قراره با همدیگه Commento (کامنتو) رو بسازیم. پلتفرمی که کامنت‌های اینستاگرام رو به‌صورت هوشمند بررسی می‌کنه؛ کامنت‌های توهین‌آمیز و مزاحم رو فیلتر و حذف می‌کنه و کامنت‌هایی که نشونه‌ی خرید دارن رو شناسایی می‌کنه تا پیج‌های فروشگاهی و اینفلوئنسرها بتونن بدون دردسر، حجم بالای کامنت‌هاشون رو مدیریت کنن🏃‍♂  

هدف من توی این چالش اینه که یه محصول واقعی رو از صفر بسازم و توی ۳۰ روز ازش ۵۰ میلیون تومن درآمد داشته باشم، اونم با شرایط واقعی ایران: اینماد، دامنه، سرور، درگاه پیامک و همه‌ی چالش‌هایی که سر راهه. نه ادعای «بخواب و پول دربیار» دارم، نه قصد دارم محتوای زرد بسازم❤️  

یه نکته‌ی مهم: این ویدئو فقط شروع ماجراست. چیزی که توی این قسمت ساخته می‌شه یه نسخه‌ی خیلی ابتدایی و اولیه‌ست و قرار نیست محصول نهایی باشه. نرم‌افزار به این سادگی‌ها نیست؛ طبیعت این کار اینه که خیلی جاها اشتباه می‌کنیم، چیزهایی رو بازنویسی می‌کنیم و مسیر رو اصلاح می‌کنیم. همین الان هم توی همین ویدئو می‌بینید که نسخه‌ی اول با ایراد جدی ساخته می‌شه و سر همین دلیل، ویدئوهای بعدی رو داریم که توش بک‌اند رو اصولی‌تر طراحی می‌کنیم🚶  

📚 چیا رو انجام میدیم؟  
• تبدیل ایده به محصول با کمک ایجنت: قبل از ساختن، امکان‌سنجی کن و محدودیت‌های API رو بشناس (مثلاً آیا اینستاگرام اجازه وصل کردن ۵۰ پیج به یک سرور و وبهوک رو می‌ده؟)  
• معماری چندلایه‌ی تشخیص کامنت: نرمال‌سازی، بلاک‌لیست، کامنت‌های حذف‌شده قبلی و در آخر هوش مصنوعی ارزون؛ به‌همراه محاسبه هزینه توکن و نتیجه تست روی کامنت‌های مختلف  
• نوشتن SRS با ایجنت Muse و بهبودش با Claude: با یه SRS خوب، حتی ایجنت ضعیف‌تر هم خروجی خوبی می‌ده  
• اتصال Claude Code به API واسط: ساخت کلید با محدودیت مدل، IP و انقضا، تنظیم settings.json، کش و ارزان‌تر شدن درخواست‌ها، و دستور /usage  
• پلاگین‌ها و اسکیل‌ها: Graphify، CodeGraph، frontend-design و Superpowers (و اینکه چرا 200 تا پلاگین و skill نباید نصب کنید)  
• مدیریت پروژه‌ی بزرگ با Claude Code: شکستن SRS دو هزار خطی به ۳۲ فایل، و یه سری ریزه‌کاری‌های کار با Claude  
• یادگیری از ایجنت: پرسیدن دلیل انتخاب PostgreSQL، Redis، RabbitMQ و Drizzle و درخواست توضیح با نمودار  
• سرور، SSH و دامنه: ساخت سرور، کلید SSH، اتصال با Termius، خرید دامنه از Cloudflare و تنظیم DNS؛ به‌همراه هشدار درباره‌ی تفاوت قیمت خرید و تمدید و بن شدن کاربران ایرانی  
• تحویل کلیدها و سرویس‌ها به ایجنت: LLM endpoint، پنل پیامک و ورود با OTP، دیپلوی از طریق گیت‌هاب
